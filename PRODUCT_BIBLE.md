# Product Bible — Neon Arcade Runner

## Product promise

Immediate one-hand neon arcade action with short sessions, clear skill expression and enough progression to make the next run meaningful.

## Core loop

Play → dodge / shoot / near-miss → collect → run summary → upgrade / live content → replay.

## Product pillars

1. **Immediate readability** — the player understands movement, danger and reward quickly.
2. **Short mobile sessions** — a run can be satisfying without a long commitment.
3. **Skill expression** — positioning, shooting and near misses should matter.
4. **Meta progression** — ships, upgrades, missions, Fleet and daily content give continuity.
5. **Respectful monetization** — automatic ads never interrupt active gameplay.

## Existing retention systems

- Daily Neon Run;
- Daily Boss;
- missions and daily challenges;
- Battle Pass;
- Fleet progression;
- LiveOps / events;
- Lucky Wheel;
- Near Miss;
- FTUE and rating flow.

## Free / Premium boundary

### Free

- complete core gameplay;
- progression and daily content;
- deterministic, capped interstitials;
- optional rewarded ads.

### Neon Premium

- no automatic interstitials;
- premium ships;
- Chaos mode;
- automatic run-gem multiplier;
- VIP daily revive;
- existing premium progression advantages.

Premium must not be justified by intentionally degrading the free experience.

## Not in this step

- monthly subscription;
- PvP;
- mandatory energy/tickets;
- forced rewarded ads;
- permanent banner spam;
- backend dependency for the core arcade loop.
